# Score Cards

نسخه اولیه وب‌اپ قابل نصب برای گوشی‌های اندرویدی سامسونگ.

## امکانات
- ثبت امتیاز دو تیم با دکمه‌های +۱، −۱، +۵ و +۱۰
- تغییر نام تیم‌ها
- انتخاب امتیاز هدف یا حالت آزاد
- ثبت تاریخچه دست‌ها
- ذخیره محلی امتیازها و تاریخچه
- پشتیبانی از نصب روی صفحه اصلی و کش آفلاین پس از اولین بارگذاری

## اجرا و نصب روی سامسونگ
1. فایل‌ها را روی یک سرویس میزبانی استاتیک با HTTPS قرار بده (مثلاً GitHub Pages یا Netlify).
2. لینک `index.html` را در Chrome گوشی سامسونگ باز کن.
3. از منوی سه‌نقطه Chrome گزینه **Add to Home screen** یا **Install app** را بزن.

نکته: این بسته APK نیست؛ یک وب‌اپ قابل نصب (PWA) است. برای ساخت APK امضاشده باید آن را با ابزار اندروید بسته‌بندی و build کرد.
